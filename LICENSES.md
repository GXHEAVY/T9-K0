## 2. Generated dictionary data: CC-BY-SA-4.0

`dictionary/words_en.tsv` is generated by `dictionary/fetch_sources.py`. It contains the
words and Zipf frequencies derived from these sources:

- the English `large` frequency list of **wordfreq 3.1.1**, for the frequencies and the
  candidate tokens;
- **SCOWL 2020.12.07**, for the spelling allow-list (en_US, sizes <= 70).

Ordinary words must appear in both sources. Contraction fragments extracted from
wordfreq bypass the SCOWL allow-list; see [dictionary filters](dictionary/README.md#filters).

`keymap/t9_dictionary_data.h` is a mechanical re-encoding of that list by
`dictionary/build_t9_dictionary.py`. Both files are Adapted Material of the wordfreq data
and are distributed under **CC BY-SA 4.0**
(<https://creativecommons.org/licenses/by-sa/4.0/>). The preferred form for modifying them
is `words_en.tsv` together with the scripts and pins in `dictionary/`.

## 4. Firmware binary: GPL-3.0

The CC-BY-SA-4.0 dictionary is compiled into the same binary. Creative Commons lists GPLv3
as a BY-SA 4.0 compatible licence (<https://creativecommons.org/compatible-licenses/>,
fetched 2026-10-12):

> GPLv3: The GNU General Public License version 3 was declared a "BY-SA–Compatible License"
> for version 4.0 on 8 October 2015. Note that compatibility with the GPLv3 is one-way
> only, which means you may license your contributions to adaptations of BY-SA 4.0
> materials under GPLv3, but you may not license your contributions to adaptations of
> GPLv3 projects under BY-SA 4.0.

CC BY-SA 4.0 section 3(b)(1) says: "The Adapter's License You apply must be a Creative
Commons license with the same License Elements, this version or later, or a BY-SA
Compatible License." The CC analysis
(<https://wiki.creativecommons.org/wiki/ShareAlike_compatibility:_GPLv3>) adds: "You must
specify version 3 of the GPL when redistributing a GPL project into which BY-SA 4.0
content is adapted". It also says the adapter must meet the GPL source requirement. Here
that is the TSV plus the generator, which this repository provides.

GPLv2 is not on the compatible list. A GPL-2.0-only program could not legally contain
the dictionary. Project code is GPL-2.0-or-later, so it may be distributed under version 3,
and ChibiOS already requires version 3. The intended licence for the combined
firmware is therefore **GPL-3.0-only**; section 5 records the audit's scope and
nonstandard terms. Project source code remains GPL-2.0-or-later, and dependency source
files retain their own licences.

## 5. Nonstandard terms and audit scope

- The notice in `quantum/sync_timer.c` and `.h` adds an obligation
  to buy a copyright holder a beer if encountered in a bar. The current upstream
  header retains this wording. The original [pull-request discussion](https://github.com/qmk/qmk_firmware/pull/10997)
  does not provide an accepted clarification. The full notice is preserved in
  `licenses/THIRD-PARTY.txt`; it is identified as MIT-style with an additional
  clause, not assigned the standard MIT identifier. Its GPL compatibility has
  not been independently established.
- `quantum/bits.h` is GPL-2.0-only, as recorded by its
  [introducing commit](https://github.com/qmk/qmk_firmware/commit/5478051d7470efb32783b1c4080a2c3f24ce3c24).
  The artifact comparison above establishes that its definitions are unused in
  this target. Preserve its licence in source archives; repeat the contribution
  check if build options, sources or toolchain change.
- Unheadered QMK files rely on the repository licence and its explicit ARM/GPLv3
  distribution guidance; unheadered LUFA and FNV files use their component terms.
  This is not a copyright-ownership audit of every historical contribution.
- wordfreq's own upstream terms (Twitter, Reddit, OSCAR, NewsCrawl) are summarized from its
  README. We did not check the original corpora.
- Dependency lists include code removed by conditional compilation or linking.
  Runtime-member counts and the sync-timer contribution check above use the
  final linker map; the notices intentionally cover a broader source set.
- `lib/chibios-contrib` has no LICENSE file in this checkout. It is not used by this build.

Dictionary" (UKACD), the list of signature words from the YAWL package,
and the 10,196 places list from the MWords package.

The 95 level includes the 354,984 single words, 256,772 compound
words, 4,946 female names and the 3,897 male names, and 21,986 names
from the MWords package, ABLE.LST from the ENABLE Supplement, and some
additional words found in my part-of-speech database that were not
found anywhere else.

Accent information was taken from UKACD.
